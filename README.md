# Comensanas2

Segunda versión de la web de Comensanas, la consulta de nutrición de Ruth Rodrigo en Valencia y Llíria.

Es una web estática de una sola página, sin dependencias ni proceso de compilación:

- `index.html`: contenido y estructura
- `styles.css`: estilos (adaptados a móvil)
- `img/`: fotos y logos en formato WebP

## Ver en local

Abre `index.html` en el navegador.

## Publicar

Puede publicarse tal cual en GitHub Pages (Settings → Pages → rama `main`, carpeta raíz) o en cualquier hosting estático.
